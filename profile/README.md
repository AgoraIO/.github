## Move faster with Agora developer tools

![Agora Skills and CLI — AI coding knowledge and one-command onboarding.](./assets/agora-tools-showcase.svg)

### Agora Skills

[Agora Skills](https://github.com/AgoraIO/skills) gives Claude Code, Cursor, Copilot, Windsurf, and other AI coding assistants the knowledge to build Agora experiences.

```bash
npx skills add github:AgoraIO/skills
```

### Agora CLI

[Agora CLI](https://github.com/AgoraIO/cli) helps you authenticate, manage Agora projects, and move from an account to a runnable quickstart.

```bash
curl -fsSL https://dl.agora.io/cli/install.sh | sh
```

Windows and restricted-network installation options are documented in the [Agora CLI repository](https://github.com/AgoraIO/cli#install).
